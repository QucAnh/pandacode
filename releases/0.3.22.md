# Stay signed in, pick models that exist

## Remote access

- **PandaCode Connect stays signed in across updates.** Updating no longer asks you to sign in again. If 0.3.20 or 0.3.21 signed you out, 0.3.22 picks up your earlier sign-in by itself, as the same computer, so the computers you trusted stay trusted. A brief Keychain hiccup right after an update is retried quietly instead of signing you out, and your sign-in renews itself before it expires.
- **The model picker shows what the other computer has.** For a task that runs on another computer, the picker lists only the providers and models installed there. If your current model isn't on the computer you pick, PandaCode switches to one that is and tells you; picking This computer again brings your choice back.

## Plan progress

- **Agents post their plan to a Progress view.** A `Progress` bar above Bots opens a sidebar view with one card per task that has a plan: five steps around the active one, `+N finished` above and `+N more` below, one colour per status. The running task stays highlighted, and the card switches to an attention tone while the run waits on an approval or a question.
- **Plans survive restarts.** Each task's plan is stored with the task, and the card is decoration only: you cannot tick it, and it never changes permissions.
- **The plan is shown once, in the approval message.** The agent posts it with the `pandacode_plan` tool, asks for approval, then updates the same list as steps finish without repeating it in chat.
- **PandaCode's plan tool now reaches every harness.** It used to be offered to Codex alone, so OpenCode, Kimi, Pi and the other harnesses were told about a tool they did not have. Other harnesses receive that one tool; Codex keeps the full app catalog.

## Known limitations

- If the earlier sign-in can't be found (for example it was removed from Keychain), sign in once more in Settings → Remote access.
- Remote access is covered by automated tests; it has not been tried between two real computers yet.
